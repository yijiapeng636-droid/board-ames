# Domain Docs

工程技能探索代码库时，应按照本文件读取领域文档。

## 探索前读取

- 仓库根目录的 `CONTEXT.md`；或者
- 如果存在根目录 `CONTEXT-MAP.md`，读取其中指向的相关上下文文档；
- 阅读 `docs/adr/` 中与当前工作相关的 ADR。

如果这些文件尚不存在，静默继续，不要因为缺少它们而中断工作或提前建议创建。后续领域建模技能会在确实形成术语或架构决策时按需创建。

## 文件结构

本项目采用单上下文结构：

/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/

## 使用领域词汇表

输出内容涉及领域概念时，应使用 `CONTEXT.md` 中定义的术语，不要改用词汇表明确排除的同义词。

如果需要的概念尚未出现在词汇表中，应先判断这是偏离项目用语，还是确实存在需要补充的领域概念。

## 标记 ADR 冲突

如果拟议改动与已有 ADR 冲突，应明确指出冲突，而不是静默覆盖已有决策。
